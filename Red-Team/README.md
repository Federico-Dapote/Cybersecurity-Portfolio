# Red Team

A collection of hands-on Red Team projects, penetration testing exercises and group CTF activities completed during the Cybersecurity & Ethical Hacking program.

## Projects

### Black Box Penetration Test – BSides Vancouver

Black-box penetration testing exercise involving service enumeration, credential discovery, brute-force testing, SSH access and privilege escalation to root.

[View project](Projects/Black-Box-Penetration-Test-BSidesVancouver/)

### OSINT & Spear-Phishing Simulation

OSINT-based adversarial simulation combining public-source research, Maltego, theHarvester and the design and analysis of a targeted spear-phishing scenario.

[View project](Projects/OSINT-Spear-Phishing-Simulation/)

### Stored XSS – DVWA

Hands-on web security project focused on Stored XSS exploitation in DVWA using JavaScript, Burp Suite and a controlled HTTP server, with testing across multiple security levels.

[View project](Projects/Stored-XSS-DVWA/)

### Vulnerability Assessment – Nmap & Nessus

Vulnerability assessment exercise using Nmap and Nessus to identify exposed services, known vulnerabilities, risk levels and possible remediation actions.

[View lab](Projects/Vulnerability-Assessment-Nmap-Nessus/)
