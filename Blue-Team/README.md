# Blue Team

A collection of hands-on Blue Team projects and labs focused on security monitoring, Windows infrastructure, threat intelligence, malware analysis and network forensics.

## Projects

### Windows Server & Active Directory Security

Windows Server 2022 security project focused on Active Directory organization, users and groups, Group Policy, NTFS and share permissions, access restrictions and remote administration.

[View project](Projects/Windows-Server-Active-Directory-Security/)

### WannaCry Malware Analysis

Dynamic malware analysis of a WannaCry sample in the tria.ge sandbox, including behavioral analysis, persistence mechanisms, dropped components and network traffic investigation.

[View project](Projects/WannaCry-Malware-Analysis/)

### Threat Intelligence & PCAP Analysis

Network traffic investigation using Wireshark and Nmap to identify indicators of compromise, reconstruct scanning activity and distinguish between different TCP scanning techniques.

[View project](Projects/Threat-Intelligence-PCAP-Analysis/)

### ANY.RUN Dynamic Malware Analysis

Dynamic malware analysis using ANY.RUN, focused on execution chains, system discovery, Registry activity, intentional delays, trace-log disabling, code obfuscation and suspicious network activity.

[View project](Projects/ANY.RUN-Dynamic-Malware-Analysis/)

## Labs

### Windows Process Analysis

Windows host analysis using Process Explorer to examine process trees, child processes, threads, handles, Registry activity and VirusTotal information.

[View lab](Labs/Windows-Process-Analysis/)

### Malware Static Analysis

Static analysis of a Windows Portable Executable using CFF Explorer, including imported libraries, PE sections and identification of suspicious executable sections.

[View lab](Labs/Malware-Static-Analysis/)

### Executable Extraction from PCAP

Network forensics exercise using Wireshark to inspect an HTTP stream, identify embedded executable data, export the transferred file and verify its true identity.

[View lab](Labs/Executable-Extraction-from-PCAP/)
